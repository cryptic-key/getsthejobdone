Paste this into Outlook.

The boxes start empty for your name, phone, and email. What you type stays in this browser. Copy the card, then paste it with Ctrl+V. Windows Outlook keeps the first line on “get done.”

Edit the template

Outlook

  1. Fill in the boxes you want on the signature.
  2. Click Copy signature.
  3. File → Options → Mail → Signatures, click in the editor, then press Ctrl+V.

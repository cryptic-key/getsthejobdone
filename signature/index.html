Gmail

  1. Click Copy signature on a computer.
  2. Settings → See all settings → General → Signature.
  3. Create a signature, paste, then Save Changes at the bottom.

Apple Mail

  1. Click Copy signature.
  2. Mail → Settings → Signatures → + and paste.
  3. Turn off “Always match my default message font.”

Outlook

  1. Click Copy signature.
  2. File → Options → Mail → Signatures, then paste.
  3. Windows Outlook usually holds the line on “get done.”
